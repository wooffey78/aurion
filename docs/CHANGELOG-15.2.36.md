# Aurion 15.2.36

- Suppression complète de l'indicateur de progression dans le noyau et le module de synchronisation.
- La synchronisation entre appareils émet un événement applicatif au lieu de recharger le document.
- Les écrans métier se rafraîchissent en interne uniquement lorsqu'aucun formulaire ou champ n'est en cours d'édition.
- Versions racine/backend alignées et cache PWA renouvelé.
- Tests de non-régression pour l'absence de barre et de rechargement forcé.
