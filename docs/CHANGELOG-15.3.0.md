# Aurion 15.3.0 — parcours guidé et dossier administratif

Cette version locale ajoute un tutoriel en sept étapes réutilisant l'organisation, les profils métier, le thème des documents, la messagerie, la signature et le journal de bord existants. L'état du tutoriel est enregistré côté serveur ; les comptes historiques dépourvus d'état ne sont pas enrôlés automatiquement. Le tableau de bord reste accessible depuis chaque étape.

Elle ajoute les adresses d'intervention multiples par client et un instantané de l'adresse sur les devis/factures, des tables additives pour les formalités et pièces administratives, un journal de bord persistant dédupliqué, un rapprochement ciblé et manuel des messages Gmail (lecture OAuth distincte), un export complété, ainsi qu'une signature HTML/texte configurable.

Le thème visuel utilise les capacités locales existantes. Les variantes de logo, favicon graphique et typographies qui ne sont pas générées par cette version sont explicitement signalées comme absentes. Le téléversement de dossier indique l'absence d'analyse antivirus configurée. Une réponse Gmail n'approuve jamais automatiquement une formalité.

Aucune donnée métier historique ni migration existante n'est réécrite par la migration 065. Aucun déploiement ou accès à une base distante n'a été effectué pendant la préparation de cette archive.
