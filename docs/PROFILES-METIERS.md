# Profils métiers

Aurion ne partage pas un catalogue universel entre métiers. Le profil est déduit de l'activité choisie et peut être ajusté par l'utilisateur.

Profils intégrés :
- Réparation smartphone : écrans, batteries, connecteurs, IMEI, garanties, SAV, transfert de données.
- Plomberie / bâtiment : tubes, raccords, sanitaire, recherche de fuite, installation, maintenance.
- Développement web / logiciel : sites, e-commerce, applications, SaaS, hébergement, licences, maintenance.
- Artisan / bâtiment : matériaux, chantiers, installation, réparation, maintenance.
- Services génériques : catalogue et prestations personnalisables.

Chaque activité conserve ses clients, fournisseurs, ressources, prestations, documents, taux et paramètres.
